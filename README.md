# 商业广告 A/B 实验与投放策略分析

## 项目简介
本项目基于 58.8 万级别的用户级广告曝光数据，评估“商业广告”相较于“无商业广告刺激（公益广告 PSA）”，能为平台带来多少真实的转化增量。通过严谨的统计学检验与时间维度下钻，旨在解决广告预算分配的 ROI 优化问题，并为投放策略提供数据支持。

## 核心业务结论
*   **实验增量**：商业广告组转化率（2.55%）显著高于对照组（1.79%），相对提升达 **43.09%**，绝对提升 **0.77pp** (p < 0.001，置信区间 [0.60, 0.94]pp)。
*   **策略建议**：广告优势在**周一、周二**最为显著；结合小时维度下钻，**14:00-16:00** 与 **20:00** 是转化黄金窗口。建议预算向该时段倾斜，而在周四全天降低出价。
*   **样本防坑**：凌晨时段（0-7点）对照组转化率出现极端的 0%，经排查为样本量极小导致的假象。分析中设定了“psa样本≥500且转化≥5”的过滤规则，剔除噪音。

## 分析链路 (Methodology)
本项目严格遵循“数据探索-实验校验-假设检验-策略下钻”的闭环：
1.  **数据摸底**：读取、清洗并观测分组样本量与原始转化率。
2.  **实验校验**：识别出数据集为 96/4 的“小流量 PSA 对照设计”。通过卡方情景分析（SRM）确认分流可信（p=0.9998），并通过敏感性分析验证对照组 2.3 万样本量在主设定下充足。
3.  **显著性检验**：采用单侧两比例 Z 检验（Z=7.37），验证广告增量极显著，并计算效应量与置信区间。
4.  **维度下钻**：从“星期”与“小时”维度探索最佳投放窗口，生成热力图，并针对小样本偏差建立过滤规则。

## 技术栈
*   **语言**：Python 3
*   **数据处理**：Pandas, NumPy
*   **统计检验**：SciPy (卡方检验), Statsmodels (功效分析, 两比例 Z 检验)
*   **数据可视化**：Matplotlib (热力图)
